Skippify PWA

Upload filerne til fx Netlify, Vercel eller GitHub Pages.

iPhone:
1. Åbn URL'en i Safari.
2. Del -> Føj til hjemmeskærm.
3. Åbn Skippify fra hjemmeskærmen.

Android:
1. Åbn URL'en i Chrome.
2. Menu -> Installer app / Føj til startskærm.

PWA-installation kræver HTTPS eller localhost.
